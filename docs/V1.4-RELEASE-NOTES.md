# Shikshly v1.4 Release Notes

## What changed

- Tailwind CSS 3 -> 4.3.x for the web app.
- Official `@tailwindcss/vite` integration added.
- Legacy PostCSS Tailwind configuration removed.
- Existing JS Tailwind theme retained through explicit `@config` compatibility loading.
- `shell-quote` override raised to the current 1.12.x release line.
- Node.js baseline raised to 22.13+.
- Added `npm run security:audit` and `npm run security:full`.
- Added v1.4 security status documentation.

## Why `npm audit fix --force` is not used

Forced audit remediation can introduce incompatible major-version changes. In particular, the audit output for the previous release proposed a downgrade of Expo and other breaking dependency changes. v1.4 instead applies compatible, targeted updates and documents advisories for which no upstream patched release exists.

## Current upstream-only caveats

As of 2026-10-07, public advisories report no patched release for:

- `braces` CVE-2026-93687 (stack-exhaustion DoS; affected through 3.0.3).
- `node-forge` CVE-2026-85393 (RSA PKCS#1 v1.5 signature verification issue; affected through 1.4.0).

These are transitive Expo/Metro/mobile-tooling dependencies. Do not replace them with an untrusted fork merely to make `npm audit` show zero.

## Validation status

The v1.3 baseline had a passing verification suite: 63/63 unit tests, a successful web production build, and 104 smoke/E2E checks with 0 failures. v1.4 source changes are limited to the web build/dependency layer and documentation, but this build environment cannot access the npm registry, so a fresh v1.4 dependency install could not be executed here. After extraction, run:

```bash
npm install
npm run verify
npm run security:audit
npm run security:full
```

Then run the real MongoDB transaction smoke test before launch.
