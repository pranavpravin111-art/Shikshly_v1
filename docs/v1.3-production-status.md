# Shikshly v1.3 implementation status

## Implemented in source

- Premium Settings workspace with account/profile, theme/language, notification preferences, active sessions, password change and separate Shikshly app rating.
- Password change endpoint with bcrypt verification and revocation of other active sessions.
- Role-aware School Workspace using the existing tenant-scoped APIs for members, invitations, students and class/teacher assignment.
- Platform Admin control plane for platform overview, school status, plan editing, support visibility and platform history.
- Motion-based page entry transitions, Sonner feedback, Lucide iconography, Tailwind styling and reduced-motion/focus-visible accessibility rules.
- Existing school rating and app rating remain separate data models/aggregates.

## Deliberately external launch gates

These cannot be made production-live by changing source code alone and must be configured with real credentials/infrastructure:

- MongoDB Atlas replica-set, backups and restore drill.
- Production domain, HTTPS and exact CORS origins.
- Razorpay live account, recurring plans, webhook secret and reconciliation testing.
- MSG91 account, DLT entity/templates, sender and delivery callbacks.
- Production email provider and verified sender/domain.
- Push notification provider/device tokens for Android/iOS.
- Monitoring, alerting, DNS, SSL and incident response.
- Legal entity, DPDP/privacy/terms/refund/support review.
- Android/iOS signing certificates, store accounts and real-device QA.

## Verification

Run after installing dependencies:

```bash
npm run verify
npm run smoke
npm run build
```

Then run the acceptance tests in `docs/launch-readiness.md` against the configured providers.
