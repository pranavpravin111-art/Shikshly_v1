# Product and integration references

These links are implementation references, not endorsements. The visual system in this project is original and uses common open-source React patterns rather than copying a school's site.

- [DinoSchool SaaS reference](https://dinoschoolsaas.techdino.in/) — product comparison/reference supplied by the founder.
- [shadcn/ui chart documentation](https://ui.shadcn.com/docs/components/aria/chart) and [Recharts accessibility guidance](https://github.com/recharts/recharts/blob/main/storybook/stories/API/Accessibility.mdx) — accessible chart and dashboard patterns.
- [MSG91 Send SMS API](https://docs.msg91.com/sms/send-sms) — provider request shape for an eventual SMS delivery adapter.
- [MSG91 DLT process](https://msg91.com/help/dlt-registration-in-india/dlt-process/) and [DLT content-template FAQ](https://msg91.com/help/dlt-registration-in-india/dlt-content-template-faqs) — India-specific setup context. Sender entity/header/template approval and provider prerequisites must be completed by the operator.
- [Government of India IP India trademark search](https://tmrsearch.ipindia.gov.in/tmrpublicsearch/) — check confusingly similar marks and relevant classes before committing to a brand.
- [ICANN Registration Data Lookup](https://lookup.icann.org/en) — check `.com` and other gTLD registration data with a registrar/availability checker. Availability can change and requires a live registrar confirmation.
